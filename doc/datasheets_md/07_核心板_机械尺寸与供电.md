## 2. 供电说明（`供电说明.png` 原文内容）

标题：**核心板内部电源示意图**

原文文字：

- 推荐使用 **5V 或 USB** 给核心板供电（绿色强调）
- **两种供电线路，选择一种即可**
- **供电线路 1**：从外部得到 5V 电压，输入稳压芯片 → 「经由稳压得到的 **3V3 供给 STM32**」
- **供电线路 2**：从外部得到 3V3 电压，直接供给 STM32
- 「稳压 IC 输出的 3V3 也可以给外部模块供电，**对外输出的最大负载电流不能超过 500ma**」

### 2.1 对本项目的电流预算意义

| 负载 | 典型电流 | 来源 |
|---|---|---|
| 屏背光（LEDA/K1~K4，4 颗白光 LED 并联） | **100 mA**（Min 80mA） | 面板规格书 p5 |
| 屏逻辑（VDD） | 手册未给出具体数值（IDD 表为空） | 面板规格书 p4 |
| STM32F407VET6 @168MHz | 手册未提供，需按第 7 章 DC 特性估算 | ST7789V 手册 p38 是屏驱动 IC 的数据，非 MCU |
| **3V3 对外可供上限** | **500 mA** | 供电说明 |

> **结论（基于以上数据）**：3.3V 轨上背光就要占掉约 100mA，加上 MCU 与屏逻辑，**余量有限**。若要扩展外设（SD 卡、WiFi 模块等），需要把背光电流、MCU 功耗一起核算，不要超过 500mA。
> **注意**：如果背光由 **5V** 供电而不是 3.3V，就不会占 3.3V 轨预算。核心板 `SPI液晶接口` 的 LEDA 是与 VCC(3.3V) 短接的（见 `06` 号文件），原则上属于 3.3V 轨负载。

## 3. 板面布局与实物识别（来自 `正面.jpg` / `反面.png`，3D 渲染图 + 背面丝印）

### 3.1 正面看到的部分（`正面.jpg`，渲染图）

| 位置 | 内容 |
|---|---|
| 左侧 | **LCD32P FPC 座**（32-pin，即原理图的 FSMC 液晶接口 FPC1），图上有红色箭头标注 **「FPC 1脚」** |
| 左下 | `BOT0` 按键（BOOT0） |
| 左上 | `RST` 按键 |
| 中间 | STM32F407VET6 主控 |
| 中右 | 一个 FPC 座，丝印 `LCD`（对应原理图的 **SPI液晶接口 U4**，12-pin） |
| 右上 | Type-C 座 |
| 右侧边缘 | 4-pin 排针组，丝印 `5V / GND / DIO / CLK` |
| 上下边缘 | 2.54mm 排针孔阵列（对应 U5 / U6 的 2×21P） |

> ⚠️ **注意**：渲染图上右边缘那组 4 个丝印 `5V/GND/DIO/CLK`，与原理图 `H1`（SWD和USART1接口，2*4P）的脚位**并非一一对应**（原理图 H1 的 8 个脚为 SWCLK/SWDIO/GND/+5V/+USART1_RX/USART1_TX/RST(经1K)/3.3V）。渲染图可能是另一个角度/另一版本的示意图，**实物接线请以背面丝印与 `06` 号文件的 H1 表为准**（该表已由矢量坐标确认）。

### 3.2 背面丝印（`反面.png`，实物照片）

可见内容：

- 板号丝印：**`LXB407VE-P1`**
- 品牌丝印：**鹿小班** + logo
- 顶部两行丝印 = U5 的 42 个脚位（对应第 5 节表格）
- 底部两行丝印 = U6 的 42 个脚位（对应第 6 节表格）
- 左侧 4 个丝印：**`3V3 / RST / TXD / RXD`**

> 左侧这 4 个丝印正是 `H1` 接口的另外 4 个脚（SWD+USART1 的 2×4P）。渲染图正面看到的 `5V/GND/DIO/CLK` 与背面看到的 `3V3/RST/TXD/RXD` 合起来，与原理图 H1 的 8 个网络可以对应上（`DIO`=SWDIO、`CLK`=SWCLK）。**此对应关系为结合两面丝印与原理图得出，建议实物通电前用万用表确认。**

> **价值提示**：`反面.png` 的丝印是本项目**接线时最可靠的实物参考** —— 每一脚对应的 GPIO 都直接印在板上。
