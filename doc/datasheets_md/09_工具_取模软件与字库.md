## 1. 字模取模：PCtoLCD2002（带触摸/无触摸通用）

### 1.1 操作步骤（转写自 PDF 第 1–2 页）

1. 打开 PCtoLCD2002 软件，点击 **`<模式>` 菜单 → 选择 `<字符模式>`**
2. 根据需求在工具栏设置字符参数：
   - **选择字体**（如「宋体」）
   - **设置字体大小**：字宽 `16`、字高 `16`（勾选「等比缩放」）
   - **设置字体样式**：`B`（粗体）/ `I`（斜体）/ `U`（下划线）
   - **设置字体旋转或镜向**
   - **调整像素位置** / **修改点阵大小**（显示「当前点阵大小：16 X 16」，可锁定/复位）
   - **调整字体位置**
3. 点击 **`<选项>`**（或工具栏对应图标）设置取模参数，弹出「字模选项」对话框，按下表设置
4. 设置完成后，点击左下角 **`<确认>`**，将自动关闭字模选项框完成设置
5. 点右下角 **`生成字模`**；需要保存则用 **`保存字模`**，清空用 **`清除数据`**

### 1.2 「字模选项」对话框的可选项（转写自 PDF 第 2 页截图）

| 分组 | 选项 |
|---|---|
| **点阵格式** | `阴码` / `阳码` |
| **取模走向** | `逆向（低位在前）` / `顺向（高位在前）` |
| **取模方式** | `逐列式` / `逐行式` |
| **输出数制** | `十六进制数` / `十进制数` |
| **每行显示数据** | 点阵 `16`（可调） |
| **自定义格式** | `C51格式` / `自定义格式`（可自定义前缀、后缀、注释前缀、注释后缀等） |
| **输出选项** | 输出索引文件 / 输出精简格式 / 输出紧凑格式（复选框） |
| 界面预览项 | 液晶面板仿真、液晶色彩、简易大小 |

**框内「取模说明」原文照抄**：

> 从第一行开始向右，每 8 个点作为一个字节，如果最后不足 8 个点就补 0。取模顺序是从低到高，即第一个点作为最低位。如 `***` 为 `10000000`。

（截图右下角还有「取模演示（从低位到高位）」的点阵示意。）

```
这里以取16*16字体为例
```

## 2. 图片取模：Image2Lcd（转写自 PDF 第 1–2 页）

### 2.1 操作步骤

1. 打开 Image2Lcd 软件，点击工具栏 **`<打开>`** 按钮，选择一张需要取模的图片
2. 设置图片取模参数（见下表），**设置完成后注意检查右下角状态栏里输出图像的尺寸是否正确**
3. 设置完成后可点 **`保存`**，工具栏还有 `重载入` / `上一幅` / `下一幅` / `设置` / `帮助` / `关于`（截图显示版本 **Image2Lcd v2.9**）

### 2.2 参数项（转写自截图，含原文红字提示）

| 参数 | 设置/可选值 |
|---|---|
| **输出数据类型** | `C语言数组(*.c)`（下拉） |
| **扫描模式** | `水平扫描` |
| **输出灰度** | `16位真彩色` |
| **最大宽度和高度** | `40 × 40` —— 原文红字提示：**「建议此处设置的数值同打开图片的像素点一致」** |
| **包含图像头数据** | 复选框 |
| **字节内像素数据反序** | 复选框 |
| **扫描方向** | `自左至右扫描` / `自底至顶扫描` |
| **高位在前** | `高位在前(MSB First)` 复选框 |
| **颜色位数** | `256色` / `4096色` / `16位彩色` / `18位彩色` / `24位彩色` / `32位彩色` / `注册` |
| **颜色排列** | `R:5bits, G:6bits, B:5bits`（即 **RGB565**）或 `R:5bits, G:5bits, B:5bits`（RGB555） |
| 输入/输出图像 | 示例：输入图像 `小火堆.bmp (40,40)`；输出图像 `(40,40)` |
| 其他按钮 | `恢复缺省值` |

**原文注意事项（照抄）**：

> 注意：最大宽度和高度设置好后，需要点击旁边按钮或者点击工具栏 `<重新载入>` 才会生效。设置完成后注意检查右下角状态栏里输出图像的尺寸是否正确。

## 3. 与本项目的对应关系

| 场景 | 用哪个工具 | 关键参数 |
|---|---|---|
| 显示中英文字符（LVGL 或自绘） | PCtoLCD2002 | 16×16、阴码、逆向、逐行式、C51 格式；中文需汉字索引 |
| 显示图片/图标（开机 LOGO、图标） | Image2Lcd | `C语言数组(*.c)`、水平扫描、16位真彩色、**颜色排列 R:5bits,G:6bits,B:5bits（RGB565）** —— 与屏初始化里 `COLMOD=0x05`（16bit/pixel，RGB565）一致 |

> **一致性说明**：本项目的 ST7789V 初始化把 `3Ah COLMOD` 设为 `0x05`（16 bit/pixel = RGB565，见 `04` 号文件），与 Image2Lcd 建议的 `R:5bits,G:6bits,B:5bits` **一致**。
> **若改用 LVGL**：LVGL 有自己的图片格式（`LV_IMG_CF_TRUE_COLOR` 等）与字体转换器（`lv_font_conv`），上述工具产出的 C 数组可作为裸数据源，但一般不需要手动取模。
