## 1. 芯片概述（原文 p12–p13）

单芯片 TFT-LCD 控制器/驱动器，**内置帧存储器（Frame Memory, FM）**。

### 2. FEATURES（原文 p13）

- 分辨率：**240 × RGB (H) × 320 (V)**
- 帧存大小：`240 × 320 × 18-bit = 1,382,400 bits`
- 驱动输出：Source 240 RGB 通道；Gate 320 通道；公共电极输出
- 颜色模式：
  - 全彩：**262K，RGB=(666)**，Idle Mode Off
  - 降色：8 色，RGB=(111)，Idle Mode On
- 可编程像素色深：**12-bit/pixel RGB(444) / 16-bit/pixel RGB(565) / 18-bit/pixel RGB(666)**
- MCU 接口：
  - 并行 8080 系列（8/9/16/18-bit）
  - 6/16/18-bit RGB 接口（VSYNC, HSYNC, DOTCLK, ENABLE, DB[17:0]）
  - **串行外设接口（SPI Interface）**
  - VSYNC 接口
- 显示特性：可编程局部显示占空比、CABC 省电、色彩增强
- 内置电路：DC/DC 变换器、可调 VCOM 生成、**NV Memory（保存初始寄存器设定与出厂值：Module ID、Module Version 等）**、Timing Controller、4 组预设 Gamma（RGB 可分开设置）
- 内置 NV Memory 内容：ID1/ID2/ID3 各 8-bit、**VCOM Offset 调整 6-bit**
- 驱动算法：（原文 p13 后段，属图形/公式章节，未提取）

## 4. 串行接口协议（§8.4，原文 p55–p62）

### 4.1 接口选择（原文 p55，Table 13）

| IM3 | IM2 | IM1 | IM0 | 接口 | 回读选择 |
|---|---|---|---|---|---|
| 0 | 1 | 0 | 1 | 3-line serial interface Ⅰ | 通过读指令（8/24/32-bit 读参数） |
| 0 | 1 | 1 | 0 | 4-line serial interface Ⅰ | 同上 |
| 1 | 1 | 0 | 1 | 3-line serial interface Ⅱ | 同上 |
| 1 | 1 | 1 | 0 | 4-line serial interface Ⅱ | 同上 |

原文说明：串口是 3 线/9-bit 或 4 线/8-bit 双向接口。3 线使用 `CSX（片选）、SCL（串行时钟）、SDA（串行数据输入/输出）`；4 线使用 `CSX、D/CX（数据/命令标志）、SCL、SDA`。SCL 仅用于与 MCU 通信，无通信时可停止。

**4-line serial interface Ⅰ 引脚（原文 Table 14）**：`CSX`=片选；`WRX`=低为命令、高为参数/数据；`DCX`=时钟；`SDA`=串行输入/输出数据。
**4-line serial interface Ⅱ 引脚**：`CSX`=片选；`WRX`；`DCX`=时钟；`SDA`=串行输入；`SDO`=串行输出。

### 4.2 命令写模式（原文 §8.4.2，p56，**核心说明，逐句照译**）

- 写模式指 MCU 向 LCD 驱动写入命令与数据。
- 3 线串口的数据包包含 1 个控制位 D/CX + 1 个传输字节；**在 4 线串口下，数据包只包含传输字节，控制位 D/CX 由 D/CX 引脚传输**。
- 若 D/CX 为 low，则该传输字节被解释为**命令字节**；若 D/CX 为 high，则该字节被存入显示数据 RAM（memory write 命令），或作为参数存入命令寄存器。
- 任何指令可按任意顺序发送。**MSB 先发送**。当 CSX 为高时串行接口被初始化，此时 SCL 时钟脉冲或 SDA 数据均无效。**CSX 的下降沿使能串行接口并标志数据传输开始。**
- CSX 为高时 SCL 时钟被忽略，CSX 高电平期间串行接口被初始化。CSX 下降沿时 SCL 可为高或低。**SDA 在 SCL 上升沿被采样。**
- D/CX 指示该字节是命令（D/CX=0）还是参数/RAM 数据（D/CX=1）。**D/CX 在 SCL 的第一个上升沿（3 线串口）或第 8 个上升沿（4 线串口）被采样。**
- 如果命令/数据字节的最后一位之后 CSX 仍保持为低，串行接口会在下一个 SCL 上升沿期待下一个字节的 D/CX 位（3 线）或 D7 位（4 线）。

### 4.3 读功能（原文 §8.4.3，p58）

- 读模式下 MCU 从驱动读寄存器值。先发送读命令（读 ID 或寄存器命令），随后字节沿反方向传输。
- 之后 CSX 需拉高才能发送新命令。**驱动在 SCL 上升沿采样 SDA（输入），在 SCL 下降沿移位输出 SDA（输出）**，因此 MCU 应在 SCL 上升沿读取。
- 发送完读状态命令后，SDA 线必须在最后一位的 SCL 下降沿之前（不迟于）置为三态。
- 支持读的命令：`RDID1/RDID2/RDID3/0Ah/0Bh/0Ch/0Dh/0Eh/0Fh`（8-bit 读）；`RDDID`（24-bit 读）；`RDDST`（32-bit 读）。

## 5. 上电/掉电时序（§8.16，原文 p136–p137）

原文要点（逐句照译）：

- **VDDI 与 VDD 可按任意顺序上电**；也可按任意顺序掉电。
- 掉电时，若 LCD 处于 **Sleep Out** 模式，则 **RESX 释放后至少 120ms** 才可关闭 VDD 与 VDDI。
- 掉电时，若 LCD 处于 **Sleep In** 模式，则 RESX 释放后 **最短 0ms** 即可关闭 VDDI 或 VDD。
- **CSX 可在任意时刻施加，也可永久接地。RESX 优先于 CSX。**

注记（原文 Note 1–4）：

1. 若未满足上电时序，**不会损坏**显示模组。
2. 上电/掉电时序期间，显示面板**不会出现异常可见效果**。
3. 上电时序结束至收到 Sleep Out 命令之间、以及收到 Sleep In 命令至掉电时序之间，显示不会出现异常可见效果。
4. 若主机在上电时序期间未能保持 RESX 线稳定，则必须在主机上电时序完成后再施加一次**硬件复位（RESX）**以确保正确工作，否则不保证功能。

### 8.16.1 非受控掉电（原文 p137）

非受控掉电指未走受控掉电时序就移除电池的情况。**既不会损坏模组也不会损坏主机接口**。若发生非受控掉电，显示会变空白且无可见异常（blank display），并保持空白直到 "Power On Sequence" 将其重新上电。

| D5 | MV | Page/Column Order：`0`=Normal Mode；`1`=Reverse Mode |
| D4 | ML | Line Address Order：`0`=LCD Refresh Top to Bottom；`1`=LCD Refresh Bottom to Top |
| D3 | RGB | RGB/BGR Order：`0`=RGB；`1`=BGR |
| D2 | MH | Display Data Latch Data Order：`0`=LCD Refresh Left to Right；`1`=LCD Refresh Right to Left |

- 原文注：D7~D5 另见 §8.12 Address Control。
- **默认值**：上电时序 `0000h`；软复位**不改变**；硬复位 `0000h`。
- 其余位（D1/D0）原手册表格中标为 `-`。

### 7.2 COLMOD `3Ah` —— 接口像素格式（原文 p224）

| Bit | 含义 |
|---|---|
| D7 | 固定 `0` |
| D6 D5 D4 | RGB 接口颜色格式：`101` = 65K of RGB interface；`110` = 262K of RGB interface |
| D3 | 固定 `0` |
| D2 D1 D0 | 控制接口颜色格式：`011` = 12bit/pixel；`101` = 16bit/pixel；`110` = 18bit/pixel；`111` = 16M truncated |

- 原文注 1：在 12/16/18-bit/pixel 模式下，写入帧存时会套用 LUT。
- 原文注 2：**向帧存写 16-bit/pixel 数据时 3Ah 应设为 `55h`；而从帧存读像素数据时应重新把 3Ah 设为 `66h`。**
  （核对：`55h` = D6D5D4=101 → 65K RGB，D2D1D0=101 → 16bit/pixel ✔；`66h` = 110/110 → 262K RGB、18bit/pixel ✔）
- **默认值**：上电时序 / 硬复位均为 `18bit/pixel`；软复位不改变。

### 7.3 CASET `2Ah` / RASET `2Bh` / RAMWR `2Ch`（原文 p198 / p200 / p202）

- `2Ah` CASET：4 个参数 —— `XS[15:8], XS[7:0], XE[15:8], XE[7:0]`，即列起始与结束地址（原文约束：`0 ≤ XS ≤ XE`）。
- `2Bh` RASET：4 个参数 —— `YS[15:8], YS[7:0], YE[15:8], YE[7:0]`，即行起始与结束地址（`0 ≤ YS ≤ YE`）。
- `2Ch` RAMWR：命令后连续写入像素数据，格式为 `Dx[17:8] + Dx[7:0]`（每个像素 2 字节传输）。写满 `(XE-XS+1)*(YE-YS+1)` 个像素后多余数据被忽略。

### 7.4 PORCTRL `B2h` —— 前后沿（Porch）设置（原文 p263）

| 位域 | 含义 |
|---|---|
| BPA[6:0] | 正常模式后沿（Back porch），**最小值 0x01** |
| FPA[6:0] | 正常模式前沿（Front porch），**最小值 0x01** |
| PSEN | 是否使能独立前后沿控制：`0`=Disable；`1`=Enable |
| BPB[3:0] / FPB[3:0] | Idle 模式后沿/前沿，最小值 0x01 |
| BPC[3:0] / FPC[3:0] | Partial 模式后沿/前沿，最小值 0x01 |

**默认值（上电 / 软复位 / 硬复位均相同）**：`0Ch / 0Ch / 00h / 33h / 33h`（5 个参数）

### 7.7 LCMCTRL `C0h`（原文 p275）

位含义：`XMY`（对 36h 的 MY 取 XOR）、`XBGR`（对 36h 的 RGB 取 XOR）、`XREV`（对 21h 反相取 XOR）、`XMH`、`XMV`（对 36h 的 MV 取 XOR）、`XMX`、`XGS`（对 E4h GS 取 XOR）。
**默认值：`2Ch`**（上电 / 软复位 / 硬复位均相同）。

### 7.8 VDVVRHEN `C2h`（原文 p277）

- 第 1 参数：`D7~D1` 固定为 0，`D0` = **CMDEN**。
  - `CMDEN=0`：VDV 与 VRH 寄存器值来自 **NVM**；
  - `CMDEN=1`：VDV 与 VRH 寄存器值来自**命令写入**。
- 第 2 参数：原文表格显示为 `1111 1111`。
- **默认值：`01h / FFh`（2 个参数）**

### 7.9 VRHS `C3h` / VDVS `C4h`（原文 p278 / p280）

- `C3h`：`VRHS[5:0]` → VAP(GVDD)。**该表为相对值**：如 `00h` = `3.55 + (vcom + vcom offset + vdv)`、`15h` = `4.6 + (...)`，步进 0.05V，`00h~27h` 有效，`28h~3Fh` 为 Reserved。
- `C4h`：`VDVS[5:0]` → VDV。`20h` = **0 V**；`00h` = -0.8V；`3Ch` = 0.7V；步进 0.025V。

### 7.10 FRCTRL2 `C6h` —— 正常模式帧率（原文 p284）

- `NLA[2:0]`：正常模式反相方式选择 —— `0x00` = **dot inversion（点反相）**；`0x07` = **column inversion（列反相）**。
- `RTNA[4:0]`：正常模式帧率，`00h`=119Hz … `1Fh`=39Hz。关键点：`0Dh`=64Hz、`0Eh`=62Hz、**`0Fh`=60Hz**、`10h`=58Hz。
- **原手册帧率公式**：
  `Frame rate = 10MHz / (320 + FPA[6:0] + BPA[6:0]) × (250 + RTNA[4:0] × 16)`
  注 2：FPA/BPA 来自命令 `B2h`；注 3：上述帧率表基于 `FPA=0Ch, BPA=0Ch`。

### 7.11 PWCTRL1 `D0h` —— 电源控制 1（原文 p290）

## 8. 其它可提取的要点

### 8.1 PWMFRSEL `CCh`（原文 p289）

`CS[2:0]` × `CLK[2:0]` 构成 PWM 频率表（单位 kHz），范围从 `CS=00h,CLK=00h` 的 **39.2kHz** 到 `CS=07h,CLK=07h` 的 **0.31kHz**。

### 8.2 SLPOUT `11h` / SLPIN `10h` / DISPON `29h` / DISPOFF `28h`

- `10h` SLPIN：进入睡眠；`11h` SLPOUT：退出睡眠（**本项目厂方初始化序列在发 `11h` 后延时 120ms**，见 `04` 号文件）。
- `28h`/`29h`：显示关/开，无参数。

### 8.3 命令可用性（Restriction）

原手册每条命令都列出「可用性表」：`Normal Mode On, Idle Mode Off, Sleep Out / Idle On / Partial On... / Sleep In` 下是否可用，以及上电时序 / 软复位 / 硬复位的**默认值**。本整理在关键命令处已摘录默认值，逐条可用性请回查对应页码。
