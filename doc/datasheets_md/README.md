## 3. 一条完整硬件链路的当前结论（多份资料交叉验证后的结果）

```
屏幕 CL28CK230-18A（18pin FPC，ST7789V，4线SPI，240×320）
        │
        ├─ SPI_SCK   ── 核心板 U4 pin2 ── PB3   (SPI3_SCK)
        ├─ SPI_SDA   ── 核心板 U4 pin7 ── PB5   (SPI3_MOSI)
        ├─ SPI_CS    ── 核心板 U4 pin6 ── PA15  (SPI3_NSS)
        ├─ SPI_DC    ── 核心板 U4 pin5 ── PD13
        ├─ 背光 BL   ── 核心板 U4 pin4 ── PD12  (LCD_BL_PD12，与 FSMC 屏接口共用)
        ├─ VCC 3.3V  ── 核心板 U4 pin9/10
        └─ GND       ── 核心板 U4 pin1/3/8/11/12
   核心板自带 SPI 屏接口（U4，12pin FPC）没有 MISO、没有屏 RESET
        │
   主控 STM32F407VET6（LXB407VE-P1 核心板）
        │
   供电：5V 或 3V3 二选一；板载 3V3 对外最大 500mA
```

> 屏幕侧的 `SPI_RESET`（18pin 的 pin2）**在核心板 SPI 屏接口上没有对应脚** —— 这是目前唯一需要你决策的接线点：接 `PC2(LCD_RST_PC2)`、还是依赖模组上电复位、还是不用复位。见 `02` 号文件第 3 节。

## 4. 整理方法与可信度说明（重要）

本次整理**没有使用任何猜测**，每条数据都可追溯到原文，方法如下：

| 材料类型 | 处理方式 |
|---|---|
| 常规 PDF（文字层完整） | PyMuPDF 按页提取全文 → 翻译 + 结构化重排，**保留原 PDF 页码**便于回查 |
| 图片型 PDF（无文字层） | 渲染成高分辨率 PNG → **读图转写**（如两份取模说明） |
| 原理图/接线图（图形连线） | 提取**矢量线段坐标 + 文字坐标**，用坐标关系**重建网络连接**（不是目测），并给出核对依据 |
| 图片资料（png/jpg） | 直接读图，按图内文字转写 |
| Office 文档 | 解压 `document.xml` 提取文字层 |
| 交叉验证 | ① 屏幕 18pin：接线图 ↔ 面板规格书 ↔ txt 说明，三者一致；② 核心板 84 脚：原理图矢量重建 ↔ **背面丝印照片**，逐脚一致；③ 初始化序列：`TN_Code.txt` ↔ `LCD.c`，逐条一致 |

每份 md 文件末尾都有「**未自动读取部分**」小节，明确写出该文件里哪些内容没能自动获取。

**无法保证的部分**：图形/波形里的时间关系、机械图尺寸的引线指向、原理图中未重建区块的连线拓扑 —— 已在 `00` 号文件逐条列出。
