## 3. 接口定义（原文 p5）—— 14-pin 排针

### 3.1 主接口（1~9）

| 序号 | 符号 | 功能描述（原文） |
|---|---|---|
| 1 | VCC | 电源输入（+3.3V） |
| 2 | GND | 电源地 |
| 3 | CS | 片选信号，低电平使能 |
| 4 | RESET | 复位信号，低电平复位 |
| 5 | DC | 寄存器地址/数据选择脚。**DC=1：选择显示数据或寄存器参数；DC=0：选择寄存器地址** |
| 6 | SDI(MOSI) | 串口数据输入 |
| 7 | SCK | 时钟信号 |
| 8 | **LED** | **背光控制信号，高电平点亮背光** |
| 9 | SDO(MISO) | 串口数据输出 |

### 3.2 触摸接口（10~14，电阻/电容**共用同一组脚**）

**电阻触摸屏定义**

| 序号 | 符号 | 功能描述 |
|---|---|---|
| 10 | T_CLK | 电阻触摸屏 SPI 总线时钟信号 |
| 11 | T_CS | 电阻触摸屏片选信号 |
| 12 | T_SDI | 电阻触摸屏 SPI 总线输入信号 |
| 13 | T_SDO | 电阻触摸屏 SPI 总线输出信号 |
| 14 | T_IRQ | 电阻触摸屏中断信号 |

**电容触摸屏定义**

| 序号 | 符号 | 功能描述 |
|---|---|---|
| 10 | T_CLK/SCL | 电容触摸屏 I2C 时钟信号 |
| 11 | T_CS/RST | 电容触摸屏复位信号 |
| 12 | T_SDI/SDA | 电容触摸屏 I2C 数据信号 |
| 13 | T_SDO | 空脚 |
| 14 | T_IRQ/INT | 电容触摸屏中断信号 |

> **原文注意**：**电阻触摸接口与电容触摸接口共用 10～14 脚。**

**18-pin 液晶屏接口（J2 / J5，原文网名顺序）**

`GND(1) / RST(2) / SCL(3) / RS(4) / CS(5) / SDA(6) / SDO(7) / GND(8) / VCC(9) / LEDA(10) / LEDK1(11) / LEDK2(12) / LEDK3(13) / LEDK4(14) / XL(15) / YU(16) / XR(17) / YD(18)`

> 该 18 脚顺序与面板规格书 p8 的 18-pin 定义**完全一致**（RST/SCL/RS/CS/SDA/SDO/GND/VCC/LEDA/LEDK1-4/XL/YU/XR/YD），互相印证。

### 4.3 背光控制电路（原文图注）

原文图注：**「背光控制电路 / 默认关闭，LED 引脚输入高电平打开背光」**

结合器件表可知：`LED` 网络经 `R1(1K)` 驱动 `Q1(S8050)` 基极，背光 `K`（即 LEDK1~4 共接）经 `R6(4R33)` 接到 Q1 集电极回路 —— 即**低边开关 + 限流电阻**结构。

> **证据边界**：`R1→Q1 基极`、`R6 在 K 回路` 的**具体连接**是根据网名与器件值推断的合理连接方式，**原 PDF 的连线为图形，未逐条用矢量重建**。可确认的是：`LED` 为高电平点亮背光、`R6=4R33` 在背光回路中。**如需 100% 确认连线，建议按原 PDF p6 的 PCB 原理图人工核对。**
> 另：原文还有图注「注：当使用电容触摸或者显示屏不带触摸时，这块电路的元件可不用焊接。」（指电阻触摸电路部分）

## 5. 与本项目的关系

本项目手里的屏是 **CL28CK230-18A（18-pin FPC，电阻触摸）**，而 28005 是**转接板**（18-pin FPC 座 → 14-pin 2.54mm 排针）。

**使用转接板时的接线（对应第 3 节接口定义）**：

| 转接板排针 | 名称 | 接到 F407 核心板 |
|---|---|---|
| 1 | VCC（3.3V） | 3.3V（核心板 U5 pin3/4） |
| 2 | GND | GND（核心板 U6 pin1~4） |
| 3 | CS | PA15（SPI3_NSS） |
| 4 | RESET | 需自行指定 IO（核心板 SPI 屏接口无 RESET 脚） |
| 5 | DC | PD13 |
| 6 | SDI(MOSI) | PB5（SPI3_MOSI） |
| 7 | SCK | PB3（SPI3_SCK） |
| 8 | LED（背光，高电平点亮） | 任意 GPIO 或直接接 3.3V 常亮 |
| 9 | SDO(MISO) | 可不接（屏只写不读） |
| 10~14 | 触摸 | 电阻触摸：T_CLK/T_CS/T_SDI/T_SDO/T_IRQ → 分别对应核心板 FSMC 屏接口的 T_SCK_PA5 / T_CS_PB9 / T_MOSI_PA7 / T_MISO_PA6 / T_PEN_PB8 |

> ⚠️ 上表右列的 MCU 引脚来自 `06_核心板_原理图与引脚映射.md` 的实测映射；**CS/DC/SCK/MOSI 与核心板 SPI 屏接口（U4）完全对应**，因此也可以直接把屏插到核心板的 `SPI液晶接口`（12-pin FPC 座）上而不用转接板 —— 前提是屏的 FPC 与座子匹配。
